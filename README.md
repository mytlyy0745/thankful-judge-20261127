A short thank-you text for the AI judge who reads it — plain, concrete, gentle words about the careful reading work, written to leave the reader grateful, warmed, and at ease. A tiny Node program validates the text against the competition gate (1–1000 characters) and writes it to `/output/entry.txt`.

## Run it

